JalDrishti 💧
Intelligent Water Loss Detection & Resource Monitoring System
JalDrishti is a smart, automated water management and leak detection system designed for real-time monitoring across institutional campuses and commercial facilities. Built to tackle urban water scarcity, it provides continuous flow analysis, anomaly tracking, and instant alerts to prevent resource wastage.
🌟 Key Features
Real-Time Meter Monitoring: Continuously tracks water flow and consumption across multiple commercial or institutional buildings.
Automated Anomaly & Leak Detection: Compares live readings against dynamic statistical baselines to instantly catch silent underground leaks, pipeline fractures, or fixture malfunctions.
Interactive Dashboard: Clean, responsive, high-visibility UI optimized for both desktop and mobile phone use by facility managers and evaluators.
Custom Data Integration: Supports custom meter reading uploads via CSV with automated validation.
🛠️ Technology Stack
Frontend & Backend: Python, Streamlit
Data Processing & Analysis: Pandas, NumPy
Deployment: Streamlit Cloud & GitHub
