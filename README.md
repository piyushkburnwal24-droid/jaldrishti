# JalDrishti 💧
*Intelligent Water Loss Detection & Resource Monitoring System*

> **JalDrishti** is an advanced, automated water management and leak detection system designed for real-time monitoring across institutional campuses and commercial facilities. Built to tackle urban water scarcity, it provides continuous flow analysis, anomaly tracking, and instant alerts to prevent resource wastage.

---

## 🌟 Key Features
* **Real-Time Meter Monitoring**: Continuously tracks water flow and consumption across multiple commercial or institutional buildings.
* **Automated Anomaly & Leak Detection**: Compares live readings against dynamic statistical baselines to instantly catch silent underground leaks or fixture malfunctions.
* **Interactive Dashboard**: Clean, responsive UI optimized for both desktop and mobile use.
